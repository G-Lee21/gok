## English — Overview & Installation
**Gok Ma Yoey** is a local-first interactive 9:16 broadcast stage & stream overlay studio for Windows 10/11:
- Launches straight to Home with zero login barrier.
- **52 interactive stage themes** running 100% offline on your PC, plus a Custom Theme Studio.
- Live viewer crowd avatars, 9-tier gift visuals, Thai/English TTS voice synthesis, 20-pose host avatar with mic lip-sync, 4 transparent game stream overlays, comment games, 6 stage minigames, and CF live commerce CSV export.
- Pure `#000000` True-Color broadcast frame with zero watermarks.

### How to Install
1. Download from **[Latest Releases](https://github.com/G-Lee21/gok/releases/latest)**:
   - `GOK-Setup-1.0.0.exe` (Windows Installer) or `GOK-Portable-1.0.0.zip` (Portable ZIP).
